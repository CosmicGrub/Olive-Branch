## How to read this

Class (one per row): **blocking** (the feature or real-family use cannot proceed until it is closed), **spec amendment** (MASTERFILE or a spec says something the plan contradicts or does not cover), **build item** (code or schema to write), **decision** (the owner must choose; a recommendation is given), **assurance gate** (external review or a real-world run that no amount of building replaces).

Evidence tag: **[code]** I read the file named on `origin/main` in this lane. **[spec]** I read the spec or MASTERFILE text named. **[doc]** taken from a planning document and not re-read in the code (its line numbers are from the date of that document). **[unverified]** could not be checked; stated so nobody builds on it.

Owner column: **Owner** = the project owner decides; **Lead** = the coordinating session; a lane name = the agent lane that would build it; **External** = someone outside the project.

Standing note: the owner has said "go with the recommendations". Decisions below are written so that is one answer; none changes a shipped behaviour until built.
