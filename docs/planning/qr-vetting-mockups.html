Adding a device safely

A scan is an introduction, never a key. It can only ask a grown-up "may this device join?" Everything that grants trust happens afterwards, in the adult's hands. Screens below are drafts of what could appear in the app: adult phone in the olive theme, child tablet in the child shell.

  1. 1 MeetSame place, same family. Automatic.
  2. 2 MatchThe adult compares a picture on both screens.
  3. 3 ApproveThe adult types their own PIN and says who it is.
  4. 4 Settle inA new device is "New" for a day.
  5. 5 Keep watchStill the approved device? One tap to stop it.

Adult shows a code, child device scans

The PIN way is still the main way. The code is optional, for two devices in the same room.

Add a device → Show my code → Child scans → Match → Approve with PIN → Settle in

Child device shows a hello card, adult scans

The "vice versa" direction. The card appears only while a grown-up has opened "being added" on that device.
