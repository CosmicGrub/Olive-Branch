# VERIFY4: choking.json / choking.md revision 4, delta check

Date 2026-11-14. Read-only adversarial check of the instructions changed in revision 4. Raw page text was fetched with curl (browser user agent) and extracted to plain text; quoted wording below is from that text. CDC and CPSC were not needed for the changed instructions. Step numbers are the `n` values (1-based); JSON array positions are one lower.

## OVERALL VERDICT: NEEDS CORRECTIONS

Nothing in the changed steps is contradicted in a way that would hurt a child, and no step is unsafe to follow. Three things stop it going to clinician review as is:

1. Nine parent-facing strings still say "see Disagreements" or "sources differ", and several others leak clinician-facing meta text (NEEDS CLINICIAN OR INSTRUCTOR, "UMass is the strictest source", "ask the clinician"). The disagreements block is displayToParents:false, so these dangle.
2. Step 12 (lone rescuer) is stated for "any age" but the 2-minute rule has two US sources for a baby and one conditional US source for a child (and that one says call at once if you saw the collapse).
3. Step 15 offers two baby CPR techniques as equal alternatives, which no source does, and the NHS text can be read as advising against the second.

- Source 23 is cited on step 13 but has no AED content; source 3 is cited on step 15 but has no CPR-technique content. Remove from those steps.
- `medicalReviewAfterEpisode` replaced `callDoctorSameDay` in choking.json only; head-injury.json and high-fever.json still use `callDoctorSameDay`. Any app consumer needs one agreed key.

- Two sources (19, 20) are WebMD Ignite content hosted by UMass Memorial Health; they carry the 2-minute child rule, the adult-pad fallback and the strong-cough-call rule. Each of those three instructions needs a second primary source before final release (AHA or Red Cross child pages were not readable; AHA PDFs return 403).
