# Olive-Branch
A new way for families and single-parents to connect with their children across great distances. Created with service members in mind.

See [BRANCHES.md](BRANCHES.md) for the branch strategy — in particular, how the per-device branches (`device/phone`, `device/tablet`, `device/pc`, `device/watch`) relate to `main` and to each other. 

Platforms: Android first, Windows alongside. iOS is scaffold-only and **on hold until the Android version is declared complete**; see [docs/roadmaps/IOS-ROADMAP.md](docs/roadmaps/IOS-ROADMAP.md).
